A launch is a grid of blocks, and a block stays on one SM

The grids of two bf16 matrix multiplies on one {device}, and what one of its {sms} streaming multiprocessors (SMs) holds

Measured: the blocks in each grid and the threads in a block, read from a profiler trace of torch.mm on one {device}, where cuBLAS picks the kernel. Not measured: which SM runs a block, and how many blocks of this kernel an SM runs at once. The strips draw one block on an SM at a time, as when a block needs more than half of one store. The limits and sizes of an SM are NVIDIA’s specification for this GPU.
