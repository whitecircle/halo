Schematic of one block of a tensor-core GEMM kernel: {steps} steps along K and {stages} shared-memory stages drawn

Schematic: the slots are not to scale, and a real block takes many more steps along K. More stages keep more loads in flight and need more shared memory. MMA is the matrix multiply-accumulate instruction of the tensor cores, and TMA, the Tensor Memory Accelerator, is not tensor memory.
