Bandwidth per GPU and per direction, on a log scale

Measured: HBM is a copy on one B300, read plus write. NVLink is a copy from one GPU to the next, at 1 GiB and 8 GiB. PCIe is a copy between pinned CPU memory and the GPU, each way, at the same two sizes. An NCCL all-reduce of {message} on {ranks} GPUs of the node reaches a bus bandwidth of {bus} GB/s. EFA is an NCCL send and receive between a GPU pair on two nodes, at 256 MiB and 1 GiB. Sockets is one weight transfer between two nodes. {load} takes the time shown at the specified rate where there is one, and a copy inside HBM reads and writes it.
